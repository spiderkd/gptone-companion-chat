# Development Context

This repository contains GPTone, a companion chat app with animated persona characters, BYOK model configuration, JEV/Codiv companion recommendations, LangGraph memory, MCP tools, and S3-compatible file uploads.

Before making broad changes, inspect the relevant implementation in `src/lib/personas.ts`, `src/lib/characters.ts`, `src/lib/personaClassifier.ts`, `src/services/agentService.ts`, and the route handlers under `src/app/api`.

Preserve license notices for the original MIT upstream project and any retained third-party assets.
